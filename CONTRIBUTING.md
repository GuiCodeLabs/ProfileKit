# Contribuindo

Obrigado por melhorar o GitHub Profile Card. Abra uma issue descrevendo o problema ou envie um pull request pequeno e verificável.

1. Explique a métrica ou o comportamento visual que está mudando. Diferencie contribuições do calendário de commits acessíveis ao token.
2. Rode `python3 -m unittest discover -s tests -v` e `npm test`.
3. Para mudanças no SVG, confira legibilidade em 410 px e aproximadamente 335 px de largura e mantenha os três idiomas.
4. Use mensagens de commit semânticas, como `fix(stats): corrige período do calendário` ou `docs: explica contribuição privada`.

Evite incluir dados pessoais de terceiros, tokens ou nomes de repositórios privados nos exemplos. O projeto é distribuído sob a [licença MIT](LICENSE).
